# TicketUp API

Bienvenue dans la documentation de l'API TicketUp.

## Description

TicketUp est une API RESTful permettant de gérer la création, la consultation et la gestion de tickets pour vos projets.

## Prérequis

- Symfony
- Composer
- php
- MySQL/Postgres

## Installation

```bash
git clone https://github.com/jehovanie/ticketUp.git
cd ticketUp-Api
composer install
```

## Technologies utilisées

- **Langage** : PHP 8.1+
- **Framework** : Symfony v7.2.5
- **API** : API Platform v4.1.7
- **Base de données** : MySQL
- **Gestionnaire de dépendances** : Composer v2.5.8
